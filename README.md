# Operação Técnica 360 — O.S. Instalação & Reparo

Dashboard publicado com base em O.S. HubSoft finalizadas e geradas nos últimos 13 meses.

- Fonte: HubSoft, somente leitura.
- Escopo: O.S. classificadas como Instalação ou Reparo.
- Empresas: Megalink, Dellink e BJ Fibra.
- Indicadores: gross, fila média, prazo, agenda, eficiência operacional, FCT, repetida, garantia e CSAT/NPS.
- O painel contém filtros globais, navegação por páginas, visão operacional paginada, exportação CSV e racional metodológico.

Os indicadores pendentes são apresentados como `—` quando o denominador/campo necessário não está disponível na base publicada; nenhum valor foi inventado.
